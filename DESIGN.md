# Design System: Rafito Juan Portfolio v2

## Visual Tone & Aesthetics
- **Theme:** High-craft minimal dark mode.
- **Palette:** Zinc scale (`bg-zinc-950`, `bg-zinc-900`, `text-zinc-50`, `text-zinc-400`, `text-zinc-500`) with precise monochromatic structural borders (`border-zinc-800`).
- **Accent:** Subtle emerald/green status badges, clear monochromatic cards, zero decorative AI-slop gradients.
- **Typography:** IBM Plex Sans (body, headings), Geist Mono (code, metadata, tags, kbd).
- **Motion Principles:** Clean, fast micro-transitions (150-200ms ease), respect for `prefers-reduced-motion: reduce`.
- **Accessibility:** WCAG 2.2 Level AA compliance, zero keyboard tab traps, full ARIA accordion and dialog bindings.

# rtk (Rust Token Killer) Usage

Always execute shell commands by prefixing them with `rtk`.
For example, instead of running `npm install`, you MUST run `rtk npm install`.
Instead of `grep -r "test" .`, you MUST run `rtk grep -r "test" .`.
Every terminal execution must have `rtk` placed at the very beginning of the command.
</RULE>
